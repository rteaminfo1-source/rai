# rteam.info — админ-панель с ролями

Загрузите на сайт рядом друг с другом:

- `admin.php` — админ-панель (новый дизайн, права по ролям);
- `_roles.php` — **новый файл**, роли и права; без него admin.php и index.php не откроются;
- `login.php` — код из Telegram спрашивается только у сотрудников с привязанным ботом;
- `bot.php` — права по ролям и привязка по коду из кабинета (`/link КОД`);
- `cabinet.php` — личный кабинет в стиле админ-панели: роль с направлением, привязки Google/Telegram, статусы заявок;
- `support.php` — страница поддержки: новый дизайн, кнопка «Позвать администратора», отвечает нейросеть Rai (загружается с GitHub, папка `support/`), сохраняет IP каждого сообщения, не пускает забаненных;
- один из `index_*.php` под именем `index.php` (`plain` — обычный; праздничные: `newyear`, `23feb`, `8march`, `9may`, `november7`).

## Роли

| Роль | Что может |
|---|---|
| 🌱 Стажёр | Чат команды, файлы и цели своего направления. Выдаётся автоматически при одобрении заявки. |
| 🧪 Тестер / ⌨️ Кодер / 🛠️ Разработчик / 🛡️ Администратор | Плюс загрузка файлов, закрепление в чате и работа своего отдела: проекты, тикеты, ответы в боте, блог. |
| 🔬 Главный Тестер / 💻 Главный Кодер / 🚀 Главный разработчик | Всё, кроме банов, ролей, штрафов и настройки прав: почта, заявки, директора, контент, настройки, логи. |
| ⚔️ Главный Администратор | Всё, кроме настройки прав ролей: баны, назначение ролей, пользователи, штрафы. |
| 👑 Руководитель | Всё, включая вкладку «Права ролей». |

- Роли назначают руководитель и главный администратор (вкладки «Команда и роли» и «Пользователи»), и только тем, кто младше их. Себе роль поменять нельзя.
- Руководитель может поменять права любой роли во вкладке «Права ролей»; они сохраняются в `roles_perms.json`.
- Владельцы `Roma_07b` и `Petryha` всегда имеют все права, их роль может менять только другой владелец. Список владельцев задаётся в `rt_owners()` в `_roles.php`.
- Роль берётся из `users.json` при каждом заходе: повышение или исключение действует сразу, без перевхода.

## Заявки

- «Принять» в панели выдаёт роль «Стажёр» и направление: для заявки «Администратор» — Администратор, для заявки «Команда» — ответ на вопрос «Направление» (на сайте это выпадающий список Кодер / Разработчик / Тестер). Перед принятием направление можно поменять.
- Вопрос «Направление» один раз сам добавляется в конец вопросов заявки «Команда». Если удалить его во вкладке «Набор», он больше не появится.
- Решение и письмо кандидату теперь обрабатывает сам `admin.php`, `decision.php` для этого больше не нужен.

## Вход

- Бот необязателен. Код из Telegram при входе спрашивается, только если у сотрудника (включая стажёров) привязан Telegram и в панели указан токен бота. Без привязки вход по паролю.
- Код действует 10 минут, на ввод 5 попыток; потом нужно снова ввести пароль, и бот пришлёт новый код.
- Второй шаг (ввод кода) не зависит от сессии: логин передаётся с формой кода, срок и попытки хранятся в `2fa_pending.json`. Страница входа не кэшируется.
- Привязать бота: кабинет → «Привязать Telegram» → отправить боту `/link КОД`. Старый способ `/link Логин Пароль` тоже работает.
- Если сотрудник потерял доступ к Telegram, в админ-панели («Пользователи» → «Управлять») есть кнопка «Отвязать Telegram».

## Бот

- Админ-кнопки в боте работают по тем же правам, что и на сайте: заявки — «Telegram-бот: отвечать», розыгрыши и рассылка — «рассылка и розыгрыши», мут — только у тех, кто банит.
- Стажёр в боте получает только код входа (`/code`).

## IP для банов

- У каждого аккаунта сохраняется последний IP и история до 10 разных адресов (обновляется при каждом заходе на сайт и при входе).
- В «Почте», «Заявках», «Тикетах» и «Чате» рядом с сообщением виден IP автора и кнопка «🎯 Забанить IP» (только у тех, кто может банить). Если IP не сохранён в самом сообщении, берётся последний IP аккаунта автора.
- Вкладка «Баны» → «Кто и откуда писал»: все сообщения в одной таблице с IP, фильтром и счётчиком записей с одного адреса.
- «Пользователи» → «Управлять»: все IP аккаунта с кнопкой бана для каждого.
- Свой собственный IP забанить нельзя.
- `support.php` сохраняет IP при создании тикета и при каждом ответе клиента; в админ-панели IP виден у каждого сообщения клиента (и «последний IP клиента» в шапке тикета) с кнопкой бана. Забаненный IP писать в поддержку не может.
- Чтобы IP сохранялся в момент отправки и в `send.php` / `apply.php`, при сохранении записи нужно добавить поле `"ip" => rt_client_ip()` (и подключить `_roles.php`).

## Вебхук бота

- Админ-панель → «Telegram-бот» → «🔗 Вебхук бота» → **«Установить вебхук автоматически»** (нужно право «Настройки сайта и токен бота»). Кнопка:
  проверяет токен, запоминает имя бота (для кабинета), сама проходит по перенаправлениям (например, на `www.`) до рабочего `bot.php`,
  ставит вебхук с секретом и сбрасывает накопившиеся сообщения. Если сайт перенаправляет `bot.php` на другую страницу или файла нет — пишет, что исправить.
- «Проверить статус» показывает адрес, очередь и последнюю ошибку Telegram. Там же есть ссылка для установки вручную.
- `bot.php` принимает запросы только с секретом, который ставит эта кнопка, — подделать сообщение от имени админа нельзя.
  Если ставите вебхук вручную старой ссылкой без `secret_token`, бот будет отвечать 403 — используйте ссылку из админки.

## ИИ поддержки (Rai)

В `support.php` первым отвечает **Rai** — своя нейросеть RTeam, а сотрудник подключается, когда нужен человек.
`support.php` — только страница: вся нейросеть лежит на GitHub в папке `support/` репозитория `rai`
(`rai-support.js` и `model.json`). Страница загружает её оттуда, нейросеть работает в браузере, а ответ сохраняется в тикет.
Сервер, Render и ключи не нужны. Как устроена сеть и как её дообучить — `support/README.md`.

- **Чему обучена.** 7095 вопросов (1229 написаны вручную, 5866 собраны из шаблонов) по 31 теме; на новых вопросах
  угадывает тему в 91% случаев.
- **Что она знает.** 31 тема: вступление в команду и статус заявки, вход и пароль, код из бота и привязка Telegram,
  золотой билет, игра в кальмара, розыгрыши, баны, оплата, апелляции, дневник, Rteamvisuals, ошибки, проекты, роли, контакты, команда, блог, рейтинг, форум…
  Если вопрос не про сайт, она ищет ответ на страницах rteam.info и в Википедии (и через `net.php`, если он указан).
  Если сеть колеблется между двумя темами, она задаёт уточняющий вопрос.
- **Передача человеку.** Клиент нажимает «🙋 Позвать администратора» — ИИ в этом тикете отключается, статус становится
  «Ждёт администратора». Вопросы об оплате, банах и апелляциях нейросеть сама передаёт администратору. Если ответ уже был,
  а вопрос повторяют, она не повторяется, а предлагает позвать человека.
- **Сама закрывает тикет.** Клиент пишет «всё решилось, можно закрывать» или «закройте тикет» — Rai отвечает и закрывает тикет,
  в нём остаётся отметка «Rai закрыл тикет: клиент подтвердил, что вопрос решён». На простое «спасибо» не закрывает, а подсказывает,
  что можно написать «можно закрывать». Если закрыл по ошибке — в админке у тикета есть кнопка «↺ Открыть снова».
- **В админ-панели** («Тикеты»): ответы ИИ отмечены ✨ и темой, которую узнала сеть. Тикеты, где нужен человек, отмечены
  оранжевым и попадают в счётчик. Любой ответ сотрудника забирает тикет у ИИ; кнопки «🛡 Забрать у ИИ» / «✨ Вернуть ИИ».
  «✨ Подсказка ИИ» пишет черновик ответа, его можно поправить и отправить от своего имени.
- **Пароли и секреты.** Нейросеть получает только текст тикета: ни `users.json`, ни паролей, ни токенов. На просьбы
  их выдать она отвечает отказом и подсказывает, как сменить пароль в кабинете или позвать администратора.

### Как включить

1. Загрузите на сайт `support.php`, `admin.php` и `_roles.php`.
2. Админ-панель → «Тикеты» → «✨ ИИ поддержки Rai» (нужно право «Настройки сайта») → галочка «ИИ отвечает в тикетах» → «Сохранить».
   «Проверить нейросеть» загрузит её с GitHub и покажет точность.
3. Адрес папки с нейросетью по умолчанию — ветка `claude/awesome-mendel-tzoqsf` репозитория `rteaminfo1-source/rai`.
   Если перенесёте её в другую ветку, впишите адрес `https://raw.githubusercontent.com/rteaminfo1-source/rai/<ветка>/support/`.
4. Необязательно: адрес `net.php` (например `https://rai.rteam.info/net.php`) — тогда Rai ищет ещё и через Google / DuckDuckGo.

- Репозиторий должен быть открытым (public). Если у посетителей GitHub не открывается, нейросеть пробует запасной адрес
  (jsDelivr). Если и он недоступен, клиент видит «ИИ сейчас недоступен — вам ответит администратор», тикет остаётся
  сотрудникам, а в шапке тикета в админке написано, почему ИИ не ответил. Можно загрузить папку `support/` на хостинг
  и указать её адрес.
- Ответ считается в браузере клиента, поэтому сайт принимает только один ответ ИИ на каждое сообщение клиента.
  Ответы Rai не стоит считать решением администрации.
- `support.php` и `admin.php` записывают `tickets.json` под блокировкой (`tickets.json.lock`), поэтому ответы клиента, ИИ
  и сотрудника не затирают друг друга. Номера тикетов не повторяются, даже если два тикета созданы в одну секунду.
- К тикетам можно прикреплять только картинки (JPG, PNG, GIF, WEBP до 8 МБ). Раньше можно было загрузить любой файл,
  в том числе `.php`, и запустить его на сайте.
- Вход на сайте действует и в поддержке, второй раз вводить пароль не нужно.

## Помощник Rai на страницах сайта (кнопка ✨)

На главной (все варианты `index_*.php`), в кабинете и на странице входа в углу есть кнопка ✨ — помощник на той же нейросети.
Он видит страницу, отвечает на вопросы, подсвечивает нужные разделы и кнопки, сам переходит на нужную страницу и нажимает
безопасные кнопки («⚡ Сделать за меня»), понимает команды «открой кабинет», «нажми войти», «покажи где сменить пароль».
Если нужен человек — открывает поддержку с заполненной темой и текстом. Подробнее — `support/README.md`.

- Загрузите обновлённые `index_*.php` (тот, что используете, под именем `index.php`), `cabinet.php`, `login.php`, `support.php`, `admin.php` и `_roles.php`.
- Выключить: админ-панель → «Тикеты» → «✨ ИИ поддержки Rai» → снять «Помощник Rai на страницах сайта».
- Пароли помощник не вводит и не видит, не нажимает «Выйти», «Удалить», «Отвязать», «Оплатить» и не отправляет формы за пользователя.
- На других страницах (`team.php`, `projects.php`, `.html`) его можно включить одной строкой — см. `support/README.md`.
