# Rai: что положить на виртуальный хостинг

Два сайта. **На хостинге только PHP и HTML** — Python не нужен: Rai работает в браузере посетителя,
а Python для браузера и распознавание текста страница скачивает с CDN (jsdelivr) при первом запуске.

| Адрес | Что это | Папка в репозитории |
|---|---|---|
| **rai.rteam.info** | Rai (чат, Code, Слайды, скриншоты) и аккаунты: регистрация, вход, Google, кабинет, чаты в аккаунте | `hosting/rai/` + страница из `build_standalone.py --cdn` |
| **aistudio.rteam.info** | AI Studio: ИИ делает сайты пользователей, API-ключи, хостинг сайтов; вход аккаунтом Rai | `hosting/aistudio/` |

**Быстрее всего:** `python make_hosting.py dist/hosting --zip rai-hosting.zip` соберёт две папки с названиями
доменов (и ZIP). Если перед этим задать переменные `GOOGLE_CLIENT_SECRET` и `SSO_SECRET`, секреты впишутся
в копии `config.php` (в репозиторий они не попадают).

```
            rai.rteam.info                                   aistudio.rteam.info
   чат · Code · Слайды · скриншоты                  сайты пользователей · API-ключи
   регистрация · вход · Google · кабинет  ── sso.php (пропуск) ──►  вход аккаунтом Rai
   чаты хранятся в аккаунте               ── sync.php: имя, почта, удаление ──►
                                             (всё подписано SSO_SECRET)
```

- **Регистрация и вход — на rai.rteam.info**: страница `login.php`, в чате — кнопка «Войти или зарегистрироваться».
- **AI Studio своих паролей не хранит**: «Войти через аккаунт Rai» → rai.rteam.info выдаёт подписанный пропуск
  (действует 2 минуты и один раз) → в студии аккаунт создаётся сам, логин = адрес сайта `sites/<логин>/`.
- **Изменения синхронизируются**: сменили имя, почту или Google в кабинете — это само доходит до AI Studio.
  Удалили аккаунт — удаляются чаты в Rai и сайт с API-ключами в AI Studio.
- Без входа Rai тоже работает — чаты тогда хранятся в браузере.

## 1. Поддомены

Создайте в панели хостинга **rai.rteam.info** и **aistudio.rteam.info** (каждому своя папка), включите HTTPS
(Let's Encrypt) и PHP 7.4 или новее.

## 2. Общий секрет

Придумайте длинную случайную строку (от 32 символов, например 64 символа 0-9a-f) и впишите её **одинаковой**
в `SSO_SECRET` обоих `config.php`. По ней студия проверяет, что пропуск и изменения профиля пришли от Rai.

## 3. rai.rteam.info

Загрузите всю папку `rai.rteam.info/` из сборки — там только `.html` и `.php`:

| Файл | Зачем |
|---|---|
| `index.html` | весь Rai: чат, Code, Слайды, скриншоты и запись экрана; движок и база знаний встроены внутрь |
| `login.php` | вход и регистрация (логин + пароль или Google) |
| `auth.php` | формы: вход, регистрация, выход, профиль, пароль, удаление аккаунта |
| `account.php` | личный кабинет: профиль, пароль, привязка Google, ссылки на Rai и AI Studio |
| `logout.php` | выход по ссылке (с подтверждением) |
| `google_start.php`, `google_callback.php` | вход через Google |
| `sso.php` | единый вход: выдаёт AI Studio подписанный пропуск |
| `me.php`, `chats.php` | для страницы Rai: кто вошёл, чаты в аккаунте |
| `config.php` | настройки — **впишите секрет Google и SSO_SECRET** |
| `assets/style.php` | стиль страниц входа и кабинета |
| `data/` | аккаунты (пароли — только хеши) и чаты в файлах `*.php` — из браузера не читаются. Нужны права на запись |

Ссылки: `https://rai.rteam.info/#code` — сразу Code, `#slides` — сразу Слайды.

## 4. aistudio.rteam.info

Загрузите всю папку `aistudio.rteam.info/`:

| Файл / папка | Зачем |
|---|---|
| `index.php` | главная студии и кнопка «Войти через аккаунт Rai» |
| `sso_start.php`, `sso_callback.php` | вход через rai.rteam.info |
| `sync.php` | принимает изменения профиля и удаление аккаунта от Rai |
| `studio.php` | рабочее место: ИИ-конструктор, предпросмотр, публикация, ZIP сайта, API-ключ, чат Rai |
| `sitegen.php` | ИИ, который создаёт и правит сайты |
| `actions.php` | кнопки студии |
| `api.php` | API по ключу (`Authorization: Bearer rai_…` или заголовок `X-API-Key`) |
| `auth.php` | выход |
| `config.php` | настройки — **впишите SSO_SECRET** |
| `assets/style.php`, `assets/script.php` | стили и скрипт студии |
| `data/` | пользователи студии и черновики (`*.php`, из браузера не читаются). Нужны права на запись |
| `sites/` | сайты пользователей: `sites/<логин>/index.html`. Нужны права на запись, PHP здесь отключён |

Файлы сайтов создаёт только ИИ студии — чужой PHP-код на хостинг не попадёт.

`.htaccess` и `web.config` в обеих папках — необязательные настройки для Apache / IIS. Без них сайты работают;
если хостинг их принимает — загрузите (для AI Studio `.htaccess` передаёт заголовок `Authorization` в `api.php`).

## 5. Google Cloud Console

console.cloud.google.com → APIs & Services → Credentials → клиент `40211315152-…`:

- **Authorized redirect URIs**: `https://rai.rteam.info/google_callback.php`
- **Authorized JavaScript origins**: `https://rai.rteam.info`

## Что не выкладывать в GitHub

`config.php` с секретами, папки `data/` и `sites/` с хостинга. В репозитории оба `config.php` лежат без секретов.
