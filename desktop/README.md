# RTeam — Админ-панель (приложение для Windows)

Настольное приложение (`.exe`) для входа в админ-панель **rteam.info**.

Это тонкая оболочка на движке **Microsoft Edge WebView2**, которая открывает
живую страницу `https://rteam.info/admin.php`. За счёт этого приложение
**само обновляется**: любое изменение `admin.php` на хостинге сразу видно в
приложении — пересобирать `.exe` не нужно.

## Возможности

- Вход и запоминание сессии между запусками (cookie хранятся в
  `%AppData%\RTeamAdmin`).
- Если вы ещё не вошли — приложение само открывает страницу входа, а после
  входа возвращает прямо в админ-панель.
- Горячие клавиши браузера: `F5` — обновить, `Alt+←` — назад, `Ctrl+±` — масштаб.
- Ссылки `target=_blank` и `window.open` открываются в этом же окне.
- Чёткая картинка на экранах с масштабированием (манифест Per-Monitor-V2 DPI),
  запуск без прав администратора.

## Требования

Windows 10/11 с установленным **Microsoft Edge WebView2 Runtime**. На
большинстве современных систем он уже есть. Если нет — приложение покажет окно
со ссылкой на бесплатную загрузку
(<https://developer.microsoft.com/microsoft-edge/webview2/>, пункт
«Evergreen Standalone Installer»).

## Как переопределить адрес

По умолчанию открывается `https://rteam.info/admin.php`. Адрес можно сменить
(например, на тестовый домен) любым из способов, по приоритету:

1. первый аргумент командной строки: `RTeamAdmin.exe https://пример/admin.php`;
2. переменная окружения `RTEAM_URL`;
3. файл `rteam.url` рядом с `.exe` — первая строка с адресом `http(s)://…`.

## Сборка из исходников

Нужен Go 1.24+. Кросс-сборка из Linux/macOS тоже работает (CGO не требуется).

```bash
# 1) ресурсы Windows (иконка, манифест, версия) — создаёт rsrc_windows_amd64.syso
go run github.com/tc-hib/go-winres@v0.3.3 make --arch amd64

# 2) сборка .exe (без окна консоли)
CGO_ENABLED=0 GOOS=windows GOARCH=amd64 \
  go build -ldflags="-H windowsgui -s -w" -o build/RTeamAdmin.exe .
```

Или просто: `./build.sh`.

Иконку можно перегенерировать: `python3 make_icon.py` (нужен `Pillow`).

## Состав

| Файл | Назначение |
|------|------------|
| `main.go` | логика приложения (окно, WebView2, маршрут входа) |
| `fatal_windows.go` | окно-подсказка, если не установлен WebView2 Runtime |
| `winres/winres.json`, `winres/icon.png` | иконка, манифест, сведения о версии |
| `make_icon.py` | генератор иконки |
| `build.sh` | сборка `.exe` одной командой |
