# Rai — собственный ИИ-ассистент Rteam на Python

Rai работает **полностью на своём движке**: без OpenAI, Claude и любых других внешних API, без ключей и без интернета.
Этот репозиторий — только Python-часть (сервер). Сайт (HTML/PHP/JS) лежит на другом хостинге и обращается к Rai по ссылке.

## Пять версий

| Версия | id | Что умеет |
|---|---|---|
| **Rai Pro Fast** | `pro-fast` | Самая быстрая: поиск по ключевым словам, калькулятор, дата и время |
| **Rai Pro** | `pro` | Основная: поиск по смыслу (TF-IDF), калькулятор, время, конвертер единиц, случайные числа |
| **Rai Pro Plus** | `pro-plus` | Всё из Pro, а ещё исправляет опечатки и раскладку (`ghbdtn` → «привет»), даёт все навыки (пароли, работа с текстом), помнит имя, отвечает на «подробнее/ещё» и подсказывает похожие вопросы |
| **Rai Pro Sun** | `pro-sun` | Всё из Plus, а ещё запоминает факты («запомни, что …»), отвечает на несколько вопросов в одном сообщении и сразу даёт подробные ответы |
| **Rai Pro Quasar** ✦ | `pro-quasar` | Самая сильная: всё из Sun, режим Code (проверка, исправление, объяснение и написание программ), ответы дополняются фактами из интернета, презентации до 16 слайдов с настоящими фото. Выбрана по умолчанию |

> **Как разложить по хостингам** — [HOSTING.md](HOSTING.md): два сайта, только PHP и HTML.
> **rai.rteam.info** — Rai (чат, Code, Слайды) и аккаунты: регистрация, вход, Google, кабинет, чаты в аккаунте
> (`hosting/rai/`). **aistudio.rteam.info** — AI Studio, вход аккаунтом Rai (`hosting/aistudio/`).
> Собрать папки для загрузки: `python make_hosting.py dist/hosting --zip rai-hosting.zip`.

## Что умеет Rai

- **Отвечает на вопросы**: своя база знаний (`knowledge.json`) + словарь из 100+ понятий (`glossary.json`):
  «что такое фотосинтез», «кто такой хакер», «столица Франции», «сравни Python и PHP». **Не знает — ищет в
  интернете**: Википедия, а через посредник на хостинге (`net.php`) — Google (если задан ключ) или DuckDuckGo;
  ответ со ссылками на источники.
- **Своя нейросеть Rai Нейро** (`neuro.js`): Лайт, Стандарт, Про, Макс и Код — на основе открытых моделей Qwen3.5
  (0,8B–9B) и Qwen2.5-Coder (Apache 2.0), без API и ключей. **Всё хранится на вашем сайте**: `ai.php` держит копии
  моделей, библиотек, Python и распознавания текста на rai.rteam.info — после первого посетителя ничего не берётся
  с чужих серверов. Включается сама, сама выбирает самую умную модель под устройство (отдельная видеокарта или
  Apple M — «Про» 4B). Есть WebGPU — работает на видеокарте (WebLLM), нет — на процессоре (wllama, в несколько
  потоков). Перед ответом ищет в интернете и **читает найденные страницы**, берёт точные сведения из базы знаний
  Rai, над сложными задачами (математика, логика, ошибки в коде) **сама думает перед ответом**, ставит ссылки. Пишет любой код, сайты и игры, отвечает на любые вопросы. Это **агент**: сам решает, когда искать в
  интернете (`ПОИСК:`), когда прочитать страницу по ссылке (`ОТКРОЙ:`), когда посчитать или проверить кодом Python (выполняет его в браузере и читает вывод), что
  **запомнить о вас навсегда** (`ЗАПОМНИ:` — видно и удаляется в окне нейросети). Режим **«Думать глубже»** (лампочка
  у поля ввода): сначала рассуждает и проверяет себя, «Ход мыслей» виден под ответом. Под ответом — «Как нейросеть
  отвечала» (поиски, код, вывод) и кнопка «Ещё вариант». Во вкладке Code нейросеть сама **запускает написанную
  программу и исправляет ошибки**, пока она не заработает.
- **Погода в любом месте**: «погода Минск», «Минск погода», «погода в деревне Малиновка Минского района», «а в Гомеле?».
  Около 200 крупных городов Rai знает сам (все падежи), сёла и посёлки ищет в Open-Meteo и OpenStreetMap с учётом
  района, области и страны; если одноимённых мест несколько — говорит, какое показал и как уточнить.
- **Мемы**: своя база популярных русских и мировых мемов (Ждун, Шлёпа, Вжух, скуф, Гигачад, Skibidi, Italian Brainrot,
  «67», Chill guy, Doge, Rickroll…) — что значит, откуда взялся, как используют; новых нет в базе — ищет в интернете.
- **Анализ по ссылке**: пришлите ссылку на видео или аккаунт **TikTok**, видео, Shorts или канал **YouTube**, канал или
  пост **Telegram**, профиль или пост **Instagram**, страницу **VK**, пост **X** или любой **сайт** — Rai покажет цифры
  (просмотры, лайки, комментарии, репосты, сохранения, подписчики), посчитает вовлечённость (ER), охват канала (ERR),
  частоту постов, лучшие посты, проверит SEO сайта и даст советы, что улучшить. С нейросетью — ещё и экспертный разбор
  с идеями для следующих публикаций. Страницы читает свой сервер на хостинге (`net.php` + `social.php`).
- **Интернет через свой сайт**: погода, курсы, перевод, Википедия, поиск и фото идут через `net.php` на
  rai.rteam.info — браузеру не мешают блокировки чужих сайтов (CORS, фильтры, расширения).
- **Форматирует ответы**: таблицы, **жирный**, *курсив*, ==выделение==, списки, блоки кода. Любой ответ
  копируется кнопкой «Копировать» с форматированием (вставляется в Word как таблица).
- **Рисует картинки** (`creative.py`, SVG без внешних сервисов): закат, рассвет, ночь, космос, горы, море, лес,
  город, пустыня, зима, сердце, цветок, абстракция, логотипы. Скачать можно в PNG и SVG.
- **Делает презентации**: обложка, план, факты, пункты с картинками слева и справа, крупные цифры, хронология,
  цитаты, сравнение в две колонки, код, таблицы, итоги. **Текст и фото — из интернета**: статья Википедии по
  разделам и настоящие фотографии из неё (без флагов и значков), цитаты — из Викицитатника. **Делает всё, что
  сказано в запросе**: «на 10 слайдов», «разделы: …», «обязательно про …», «с таблицей / цитатой / цифрами /
  хронологией», «сравни X и Y», «без картинок» — и честно пишет, чего не нашёл. Годы и числа в тексте Rai сам
  превращает в хронологию и «цифры». Любые цвета словами: «в синих тонах», «чёрно-золотая», «фон белый,
  акцент зелёный», `#7c3aed`. Пустых слайдов-заготовок нет: если материала не нашлось, Rai так и скажет.
  Если включена нейросеть — план и тексты слайдов пишет она, а цвета и картинки остаются от Rai. Смотреть на
  весь экран, скачать **PowerPoint (.pptx)** — открывается и правится в PowerPoint, Google Slides, Keynote —
  `.html` (можно распечатать в PDF) или ZIP с картинками.
- **Архив**: «сделай архив чата» — ZIP со всеми ответами (`чат.md`), картинками, презентациями и кодом.
- **Скриншоты и запись экрана**: скрепка (или Ctrl+V, или перетащить файл), кнопка «Экран» — снимок или
  запись экрана. Текст распознаётся прямо в браузере (Tesseract, папка `ocr/`), Rai отвечает на вопросы
  с экрана: выбирает вариант в тесте, решает примеры, проверяет код, переводит.
- **Вкладка «Слайды»**: презентация по теме и цветам, миниатюры, большой предпросмотр, правка каждого слайда
  (тип, текст, пункты, цифры, даты, цитата, сравнение, картинка слева/справа, переход), палитры и свои цвета,
  показ на весь экран, PowerPoint/HTML/ZIP/PDF.
- **Сайты и программы по описанию** (Pro Plus, Sun, Quasar): «сайт кофейни «Зерно» в тёмных тонах с меню и
  отзывами» — готовый сайт, правки словами («добавь раздел цены», «сделай синим»). Игры (тетрис, 2048,
  пинг-понг, арканоид, змейка), приложения (погода, конвертер валют, пианино, рисовалка), боты, функции.
- **Вкладка Code**: редактор с подсветкой и файлами проекта, запуск Python (в фоне, с `input()` и графиками
  matplotlib), JavaScript и HTML/CSS прямо в браузере, ошибки с подсказками по-русски и переходом к строке,
  ИИ-помощник: проверить, исправить (одной кнопкой «Применить»), объяснить, прокомментировать, написать
  программу по описанию. `Ctrl+Enter` — запуск, `Ctrl+/` — комментарий. Проект скачивается ZIP-архивом.
- **Голос**: кнопка микрофона — диктовка (Chrome/Edge), кнопка «Озвучить» — чтение ответа вслух.
- **Разные чаты**: список слева, у каждого чата своя история, версия и память. Хранятся в браузере.
- Навыки: калькулятор, дата/время, конвертер, таблица умножения, пароли, работа с текстом, случайности.

- **Погода** с картинкой и прогнозом на 4 дня: «погода в Казани», «будет ли дождь завтра».
- **Валюты**: «курс доллара», «100 евро в рублях», «курсы валют» (27 валют).
- **Перевод** с автоопределением языка (50+ языков): «переведи на английский: доброе утро», «как по-немецки кошка».
- **Поиск в интернете** (Википедия, с фото): «найди в интернете Эйфелева башня». Если Rai сам не знает ответа,
  он ищет сам.
- **Языки программирования** (`proglangs.py`, 49 языков): «что такое Rust», «hello world на Go»,
  «какие языки программирования ты знаешь».
- **Вход и регистрация**: по логину и паролю или через Google. Чаты сохраняются в аккаунте.

Погода, курсы, перевод и поиск берутся из бесплатных открытых сервисов без ключей (Open-Meteo, open.er-api.com /
ЦБ РФ, MyMemory, Википедия) — без интернета этих данных не получить. Всё остальное Rai делает сам.

Если Rai не знает ответа, он честно говорит об этом и подсказывает похожие темы, а в Pro Sun его можно
научить прямо в чате: «запомни, что квазар — это …». Постоянные знания добавляйте в `knowledge.json` и `glossary.json`.

## Страница чата (`index.html`)

`index.html` — готовый чат с выбором версии. Он сам выбирает, как работать:

- если страницу отдаёт Python-сервер Rai (`python app.py` или хостинг) — запросы идут на сервер;
- если страница лежит на любом статическом хостинге (GitHub Pages, обычный веб-хостинг, raw.githack) —
  **те же `.py` файлы запускаются прямо в браузере** через Pyodide (Python в WebAssembly). Сервер не нужен.
  Первая загрузка ≈ 13 МБ (из папки `pyodide/` рядом со страницей, а если её нет — с CDN jsdelivr/unpkg),
  потом браузер берёт из кэша. Если загрузить не вышло, страница пишет почему и предлагает попробовать снова.

**Один файл `rai.html`** — тот же чат, в который уже встроены все `.py` и `knowledge.json`.
Его можно просто скачать и открыть в браузере или положить на любой хостинг одним файлом
(нужен только интернет для загрузки Pyodide). После правок в `.py` или `knowledge.json`
пересоберите его: `python build_standalone.py`.

**Протестировать сразу из GitHub:** `https://raw.githack.com/rteaminfo1-source/rai/<коммит>/index.html`

**Постоянная ссылка через GitHub Pages:** Settings → Pages → Source: *Deploy from a branch* →
выберите ветку и папку `/ (root)` → Save. Через минуту чат откроется по адресу
`https://rteaminfo1-source.github.io/rai/`.

**Только `index.html` на своём хостинге, а Python — из GitHub:** положите `index.html` на хостинг и
перед ним (в `<head>`, до остальных скриптов) укажите, откуда брать файлы (вместо `main` — ваша ветка):

```html
<script>
  window.RAI_CONFIG = {
    pyBase: "https://raw.githubusercontent.com/rteaminfo1-source/rai/refs/heads/main/"
  };
</script>
```

Если запущен Python-сервер, вместо этого укажите его адрес: `window.RAI_CONFIG = {api: "https://rai-xxxx.onrender.com"}`.
Для быстрой проверки то же самое можно передать в адресе: `index.html?api=...` или `index.html?py=...`.

## Запуск на хостинге из GitHub

Нужен хостинг с поддержкой Python. Обычный PHP-хостинг Python не запускает.

**Render.com (бесплатно):** New → Blueprint → выберите этот репозиторий. Render сам прочитает `render.yaml`.
Вручную: New → Web Service → репозиторий `rai`,
Build: `pip install -r requirements.txt`,
Start: `gunicorn app:app --bind 0.0.0.0:$PORT --workers 1 --threads 8`.

Так же подойдут Railway, Koyeb (они используют `Procfile`), PythonAnywhere или свой VPS.
Когда сервер запустится, вы получите ссылку вида `https://rai-xxxx.onrender.com`.

Переменные окружения (см. `.env.example`):

- `ALLOWED_ORIGINS`: адрес вашего сайта, например `https://rai.rteam.info`. Тогда запросы к Rai будут приниматься только с него.
- `RAI_DEFAULT_VERSION`: версия по умолчанию (`pro`).
- `RAI_ADMIN_TOKEN`: секрет для обучения через `/api/teach`.
- `RAI_TZ`: часовой пояс (`Europe/Moscow`).

## Аккаунты

На rai.rteam.info (папка `hosting/rai/`, PHP) есть аккаунты: регистрация и вход (в том числе через Google) на
странице `login.php`, личный кабинет `account.php`, чаты сохраняются в аккаунте. Тот же аккаунт открывает AI Studio
(единый вход). Без входа — и на GitHub Pages — Rai тоже работает, чаты тогда хранятся в браузере.

## API

| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/versions` | Список версий |
| GET | `/health` | Проверка, что сервер жив |
| POST | `/api/chat` | Вопрос → ответ |
| POST | `/api/chat/<версия>` | То же, версия в адресе (`/api/chat/pro-sun`) |
| POST | `/rai.php`, `/rai` | Совместимость со старым `chat.js` |
| POST | `/api/code` | Код: `{"action": "check" \| "fix" \| "explain" \| "comment" \| "generate", "code", "lang", "prompt"}` |
| POST | `/api/teach` | Научить новому ответу (нужен `RAI_ADMIN_TOKEN`) |

Запрос:

```json
{"message": "что такое python?", "version": "pro-plus", "session_id": "любая-строка-пользователя"}
```

Ответ:

```json
{"answer": "Python — простой и мощный язык…", "version": "pro-plus", "version_name": "Rai Pro Plus", "intent": "python"}
```

`session_id` нужен, чтобы Pro Plus и Pro Sun помнили имя и факты. Это любая строка до 64 символов из букв, цифр и `_.-`.

## Подключение к сайту

В `chat.js` на сайте поменяйте адрес сервера и добавьте версию:

```js
const backendUrl = "https://rai-xxxx.onrender.com/api/chat";   // ваша ссылка

let sessionId = localStorage.getItem("rai_session");
if (!sessionId) {
    sessionId = Math.random().toString(36).slice(2) + Date.now().toString(36);
    localStorage.setItem("rai_session", sessionId);
}

// версия: "pro" | "pro-fast" | "pro-plus" | "pro-sun"
// например из <select id="raiVersion">…</select>
function currentVersion() {
    const el = document.getElementById("raiVersion");
    return el ? el.value : "pro";
}

// внутри sendRequest():
const response = await fetch(backendUrl, {
    method: "POST",
    headers: {"Content-Type": "application/json"},
    body: JSON.stringify({message: text, version: currentVersion(), session_id: sessionId})
});
const data = await response.json();
addBlock(data.answer || "Результат не получен.", "rai");
```

Выбор версии в `chat.php`:

```html
<select id="raiVersion">
    <option value="pro">Rai Pro</option>
    <option value="pro-fast">Rai Pro Fast</option>
    <option value="pro-plus">Rai Pro Plus</option>
    <option value="pro-sun">Rai Pro Sun</option>
</select>
```

## Как научить Rai новому

**Способ 1: в `knowledge.json`.** Добавьте блок и сделайте push в GitHub. Хостинг обновится сам.

```json
{
  "id": "schedule",
  "title": "Расписание созвонов",
  "patterns": ["когда созвон", "во сколько собрание", "расписание встреч"],
  "answers": ["Созвон команды — по пятницам в 19:00."],
  "more": "Ссылка на созвон публикуется в чате команды за час до начала."
}
```

- `patterns`: разные формулировки вопроса. Чем их больше, тем лучше Rai понимает.
- `answers`: варианты ответа, Rai выбирает случайный. `{name}` заменяется на «, Имя», если имя известно.
- `more`: подробности. Их показывает Pro Sun сразу, а Pro Plus по команде «подробнее».

**Способ 2: без правки кода, через `/api/teach`** (нужен `RAI_ADMIN_TOKEN`):

```bash
curl -X POST https://rai-xxxx.onrender.com/api/teach \
  -H "Content-Type: application/json" -H "X-Rai-Token: ваш_секрет" \
  -d '{"patterns": ["когда созвон"], "answer": "По пятницам в 19:00."}'
```

Выученное сохраняется в `learned.json` на сервере. На бесплатных хостингах этот файл стирается при перезапуске, поэтому постоянные знания лучше добавлять в `knowledge.json`.

## Важно

- Память сессий (имя, факты) хранится в оперативной памяти сервера и пропадает при перезапуске. Поэтому сервер запускается с одним воркером (`--workers 1`).
- Движок Rai (Python) — не генеративная нейросеть: он отвечает по базе знаний, навыками и поиском в интернете.
  Свободные ответы и код любой сложности пишет нейросеть в браузере (`neuro.js`); без неё Rai тоже работает.
