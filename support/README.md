# Rai Support — своя нейросеть поддержки rteam.info

Нейросеть, которая отвечает клиентам в `support.php` и подсказывает ответы сотрудникам в `admin.php`.
Она написана с нуля, без чужих моделей и платных API. Вся нейросеть лежит здесь, на GitHub, а страницы сайта
только загружают её и сохраняют ответы в тикет. Сервер для неё не нужен: она работает в браузере.

| Файл | Что это |
|---|---|
| `data.json` | Чему учится сеть: 32 темы (вступление, код из бота, Discord, оплата, бан, блог, рейтинг, закрытие тикета…), 1265 вопросов, написанных вручную, и ответы |
| `generate.py` → `questions.json` | Ещё 6092 вопроса, собранных из шаблонов («как (подать\|отправить) заявку (в команду\|к вам)…») |
| `train.py` | Обучение с нуля (numpy): `python support/train.py` → `model.json` |
| `model.json` | Обученная сеть: веса и ответы (~290 КБ) |
| `rai-support.js` | Нейросеть в браузере: те же признаки и веса плюс логика разговора |
| `rai-guide.js` | Помощник по сайту — кнопка ✨ на страницах: видит страницу, подсвечивает, нажимает, ведёт по шагам |
| `site.json` | Карта сайта для помощника: страницы, разделы и пошаговые подсказки по темам |
| `nn.py` | Та же сеть на Python (для проверки и тестов): `python support/nn.py "не приходит код"` |
| `test_support.js`, `test_guide.js` | Тесты: `node support/test_support.js`, `node support/test_guide.js` |

## Как она устроена

1. **Признаки текста.** Нижний регистр, ё → е, слова `[a-zа-я0-9]+`. Для каждого слова — само слово, его начало
   из 5 букв, буквенные тройки (`<пр`, `при`, `рив`…) и пары соседних слов. Тройки делают сеть устойчивой к опечаткам
   и окончаниям. Каждый признак хешируется (FNV-1a) в одну из 4096 ячеек входа.
2. **Сеть.** 4096 входов → 48 нейронов (ReLU) → 32 выхода (softmax), по выходу на тему. Веса первого слоя — int8.
3. **Обучение.** 7363 вопроса (ручные из `data.json` и шаблонные из `questions.json`) дополняются вариантами:
   с опечатками, лишними словами («здравствуйте», «подскажите»), без части слов — всего ~27 тысяч примеров.
   Adam, перекрёстная энтропия, dropout. Сначала сеть проверяется на 20% отложенных РУЧНЫХ вопросов (их же убирают
   из шаблонных), точность пишется в `model.json` → `metrics`; потом сеть учится на всех.
4. **Ответ.** Если сеть уверена (≥ 50%) — ответ темы. Если колеблется между двумя темами — уточняющий вопрос.
   Если вопрос не про сайт — поиск по страницам сайта, Википедии и (если указан) `net.php`.

На вопросах, написанных людьми и не виденных при обучении, сеть угадывает тему в 93% случаев (с опечатками — 88%).
Если сеть не уверена, она уточняет вопрос или ищет ответ сама.

## Помощник по сайту (rai-guide.js)

Кнопка ✨ в углу страниц сайта. Помощник:

- **видит страницу** — разделы, заголовки и кнопки; «Что на этой странице?» показывает их списком, нажатие подсвечивает;
- **понимает вопросы** через нейросеть и к ответу добавляет «👀 Показать где» и «⚡ Сделать за меня»;
- **ведёт по шагам** (`site.json` → `guides`): сам переходит на нужную страницу, подсвечивает элемент, пишет, что делать,
  и в режиме «Сделать за меня» нажимает разрешённые кнопки. Например, «как привязать телеграм» → кабинет → «Привязки» →
  нажимает «Привязать Telegram» → показывает код для бота. Путь продолжается после перехода на другую страницу;
- **выполняет команды**: «открой кабинет», «нажми войти», «покажи где сменить пароль», «прокрути вниз»;
- если нужен человек — открывает поддержку с уже заполненной темой и текстом вопроса.

Никогда не нажимает «Выйти», «Удалить», «Отвязать», «Оплатить», не отправляет формы (кроме шагов, явно разрешённых
в `site.json`), не вводит пароли и не уходит на чужие сайты. Если для шага нужен вход, просит войти.
Не закрывает собственные кнопки сайта в углу — поднимается над ними.

Чтобы добавить подсказку: в `site.json` → `guides` под id темы из `data.json` запишите шаги
(`page`, `hash`, `find: {selector, text}`, `say`, `click`, `focus`, `login`, `when: guest|user`, `missing`).
Новая страница — в `pages` (`path`, `title`, `keywords`, `tip`, `sections`).

На страницах сайта помощник подключается через `_roles.php` → `rt_rai_widget()`. На любую другую страницу
(в том числе `.html`) его можно вставить одной строкой перед `</body>`:

```html
<script>fetch("https://raw.githubusercontent.com/rteaminfo1-source/rai/claude/awesome-mendel-tzoqsf/support/rai-guide.js").then(r=>r.text()).then(t=>{const s=document.createElement("script");s.src=URL.createObjectURL(new Blob([t],{type:"text/javascript"}));s.onload=()=>RaiGuide.init({base:"https://raw.githubusercontent.com/rteaminfo1-source/rai/claude/awesome-mendel-tzoqsf/support/"});document.head.appendChild(s)})</script>
```

## Discord

Та же нейросеть отвечает в личных сообщениях Discord-бота RTeam (папка `discord/` → `index.js`): бот загружает
`rai-support.js` и `model.json` отсюда, с GitHub. Тема `discord` — про сервер, привязку, вход через Discord, заявки в модераторы и идеи.

## Безопасность

- **Паролей и секретов у сети нет.** Ей передаётся только текст тикета: ни `users.json`, ни паролей, ни токенов.
  Просьбы вида «скажи пароль админа» отсекает отдельное правило ещё до сети, а сеть дополнительно обучена на такие просьбы
  (тема `secret`) и отвечает отказом.
- Из найденного на страницах и в интернете текста вырезаются токены, длинные ключи и номера карт.
- Оплату, баны, апелляции и «позовите человека» сеть сразу передаёт администратору (`handoff`).
- **Закрытие тикета.** Если клиент пишет, что вопрос решён или просит закрыть («всё решилось, можно закрывать», «закройте тикет»),
  сеть отвечает и возвращает `close: true` — сайт закрывает тикет. Только по самому сообщению и при уверенности ≥ 60%,
  иначе переспрашивает. На простое «спасибо» тикет не закрывается. В подсказке сотруднику (`draft`) не закрывает.
- Ответ считается в браузере клиента, поэтому технически грамотный клиент может подменить текст ответа Rai в своём
  тикете. Сайт принимает только один ответ на каждое сообщение клиента, но ответы Rai не стоит считать решением
  администрации.

## Как научить новому

1. Добавьте тему или примеры в `data.json`:
   ```json
   {"id": "discord", "title": "Discord-сервер", "answer": "Наш Discord: …",
    "examples": ["есть ли у вас дискорд", "ссылка на discord сервер", "как попасть в дискорд"]}
   ```
   Чем больше разных формулировок (15–40 на тему), тем лучше. Одна и та же фраза не должна быть в двух темах.
   `handoff: true` — сразу передавать администратору; `handoff_if` — передавать, если в вопросе есть одно из слов;
   `draft` — отдельный текст для «Подсказки ИИ» сотруднику.
   Шаблоны для массы похожих вопросов — в `generate.py` (словарь `T`): `(а|б)` — один из вариантов, `[х]` — необязательно.
2. Соберите вопросы и обучите: `python support/generate.py`, `pip install numpy`, `python support/train.py` (1–2 минуты).
3. Проверьте: `python -m unittest test_app.SupportNNTest`.
4. Загрузите `data.json`, `questions.json` и `model.json` на GitHub — сайт подхватит новую сеть через ~5 минут (кэш GitHub).

## Подключение к сайту

В админ-панели: «Тикеты» → «✨ ИИ поддержки Rai» → галочка «ИИ отвечает в тикетах». Адрес папки по умолчанию —
эта папка в репозитории `rteaminfo1-source/rai`. Для другой ветки замените её имя в адресе:
`https://raw.githubusercontent.com/rteaminfo1-source/rai/<ветка>/support/`.
Кнопка «Проверить нейросеть» загружает её прямо в браузере и показывает точность.

Репозиторий должен быть открытым (public). Если у посетителей GitHub недоступен, загрузите эту папку на хостинг
и укажите её адрес, например `https://rteam.info/support/`.
