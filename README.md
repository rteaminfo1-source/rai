# Rai — собственный ИИ-ассистент команды Rteam

**Сайт:** [rai.rteam.info](https://rai.rteam.info) · **Чат:** [rai.rteam.info/chat.html](https://rai.rteam.info/chat.html) ·
**AI Studio:** [aistudio.rteam.info](https://aistudio.rteam.info) ·
**Приложение:** [Windows, macOS, Linux](https://github.com/rteaminfo1-source/rai/releases/latest)

Rai работает **на своём движке и своей нейросети** — без OpenAI, Claude и других платных API, без ключей.
Движок написан на Python и запускается **прямо в браузере** (Pyodide). Нейросеть **Rai Нейро** — открытые модели
Qwen, они тоже работают в браузере, на видеокарте или процессоре посетителя. Сервер нужен только для аккаунтов,
оплаты и посредника в интернет. Хватает обычного PHP-хостинга.

## Что умеет

| | |
|---|---|
| 💬 **Отвечает на вопросы** | Своя база знаний, энциклопедия на ~15 000 тем из Википедии (работает без интернета). Чего не знает — ищет в интернете и даёт ссылки. Сравнивает («что лучше A или B»), отвечает про даты жизни, места, мемы |
| 🧠 **Нейросеть Rai Нейро** | Модели Лайт, Стандарт, Про, Макс, Код (Qwen3.5 0,8B–9B, Qwen2.5-Coder 7B). Сама ищет в интернете, читает страницы, проверяет себя кодом на Python, помнит факты о человеке, режим «Думать глубже». Модели хранятся на вашем сайте (`ai.php`) |
| 💊 **Лекарства** | Что за препарат, от чего, нужен ли рецепт, чем заменить, как называется в другой стране (Россия и СНГ, США, Великобритания, Германия, Турция и др.), что можно принять при симптоме и когда срочно к врачу. Страна определяется сама |
| 💻 **Code** | Редактор с подсветкой, запуск Python, JS, HTML прямо в браузере, проверка и исправление ошибок, программы, сайты и игры по описанию |
| 🖼 **Слайды** | Презентации с текстом и фото из интернета, проверкой качества, анимациями. Экспорт в PowerPoint, HTML, PDF |
| 📎 **Файлы и картинки** | Читает любые файлы: Word, Excel, PowerPoint, PDF (и сканы), код, архивы, аудио и видео (расшифровка речи). Видит, что на картинке, распознаёт текст. Запоминает документы и отвечает по ним |
| 🔗 **Анализ по ссылке** | TikTok, YouTube, Telegram, Instagram, VK, X, сайты: цифры, вовлечённость, советы |
| 🛠 **100+ функций** | Погода, курсы валют, перевод, калькуляторы, конвертеры, генераторы, игры и викторины. «Все функции» в чате покажет список |
| 📚 **Самообучение** | Запоминает ответы нейросети и оценки 👍/👎, в следующий раз отвечает сам |
| 🔔 **Уведомления** | Push-уведомления даже при закрытом сайте: «Rai ответил», новости, «оплата прошла» |
| 🌐 **AI Studio** | Сайт по описанию: нейросеть придумывает разделы и пишет тексты (или весь код со своим дизайном), правки словами, публикация, API-ключи |
| 🛡 **Правила** | Модерация (мат, 18+, наркотики и др.): Rai останавливает диалог, админ получает уведомление и может заблокировать |

Приветствие в каждом новом чате, обращение по имени, обязательный вход в аккаунт, тарифы с оплатой через Platega,
акции и промокоды, роли «Создатель» и «Разработчик», приложение для компьютера с автообновлением.

## Разработка

```bash
pip install -r requirements.txt
python -m unittest test_app        # все тесты (PHP-тесты запускаются, если установлен php)
python app.py                      # чат на http://localhost:8000 (движок на сервере)
python build_standalone.py         # rai.html — чат одним файлом (движок в браузере)
```

Чат можно открыть и без Python-сервера: положите `index.html` рядом с `.py` файлами на любой статический хостинг,
движок запустится в браузере.

## Выкладка на хостинг

```bash
python make_hosting.py dist/hosting --zip rai-hosting.zip
```

Получатся папки `rai.rteam.info/` и `aistudio.rteam.info/`: в каждой только `.php` и `.html`. Как настроить домены,
секреты, Google-вход, Platega и права на папки, написано в **[HOSTING.md](HOSTING.md)**.

**Автовыкладка.** Если в Settings → Secrets → Actions вписать `FTP_SERVER`, `FTP_USERNAME`, `FTP_PASSWORD`, а в
Variables — `RAI_DIR` и `STUDIO_DIR`, каждый push сам загружает изменённые файлы по FTP. Файлы `config.php` с вашими
ключами, папки `data/` и `sites/` при этом не трогаются.

**Админ-панель.** `python make_admin.py admin.php готовый/admin.php --key ВАШ_КЛЮЧ` встраивает вкладки «Rai: подписки»,
«Rai: правила», «Rai: уведомления» и «Rai: скидки» в админку rteam.info. Готовый файл содержит ключ, поэтому
в GitHub его не выкладывайте.

## Что собирает GitHub (Actions)

| Workflow | Что делает |
|---|---|
| «Выкладка на хостинг» (`deploy-hosting.yml`) | Собирает сайты и выкладывает по FTP |
| «Приложение Rai» (`desktop.yml`) | Собирает приложение для трёх систем и выпускает релиз; приложения обновляются сами |
| «Знания Rai» (`knowledge.yml`) | Энциклопедия из Википедии и Wikidata, обновляется ежедневно |
| «Лекарства Rai» (`medicines.yml`) | База препаратов из Wikidata и Википедии, раз в месяц |
| «Зрение Rai», «Проверка зрения» | Словарь понятий для распознавания картинок и проверка в настоящем Chrome |

Любой из них можно запустить вручную: Actions → нужный workflow → Run workflow.

## Как научить Rai новому

- **В `knowledge.json`**: добавьте блок `{"id", "title", "patterns": [формулировки вопроса], "answers": [ответы], "more"}`.
  `{name}` в ответе заменяется на имя человека.
- **В чате**: нажмите 👍 под хорошим ответом нейросети — Rai запомнит его. 👎 — забудет.
- **Документом**: прикрепите файл — Rai запомнит его и будет отвечать по нему в любом чате.

## Python-сервер (необязательно)

`app.py` отдаёт чат и принимает запросы: `POST /api/chat` с `{"message", "version", "session_id"}` → `{"answer", "intent"}`,
`GET /api/versions`, `POST /api/code`, `POST /api/teach` (нужен `RAI_ADMIN_TOKEN`), `GET /health`.
Запуск на Render: New → Blueprint → этот репозиторий (`render.yaml`). Переменные — в `.env.example`.

## Источники и лицензии

- Модели нейросети: Qwen3.5 и Qwen2.5-Coder (Apache 2.0).
- Энциклопедия и лекарства: тексты Википедии (CC BY-SA 4.0, источник указан в ответах), данные Wikidata (CC0).
- Python в браузере: Pyodide (MPL 2.0). Распознавание текста: Tesseract.js (Apache 2.0). Зрение: CLIP через transformers.js.
- Сведения о лекарствах — справка, а не назначение: Rai всегда советует обратиться к врачу и не помогает достать
  рецептурные препараты без рецепта.

Секреты (ключи Google, Platega, `SSO_SECRET`, `ADMIN_API_KEY`) в репозитории не хранятся: только в `config.php`
на хостинге или в Secrets на GitHub.
