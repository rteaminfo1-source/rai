# Rai: что положить на виртуальный хостинг

Два сайта. **На хостинге только PHP и HTML** — Python не нужен: Rai работает в браузере посетителя,
а Python для браузера и распознавание текста страница скачивает с CDN (jsdelivr) при первом запуске.

| Адрес | Что это | Папка в репозитории |
|---|---|---|
| **rai.rteam.info** | Главная с тарифами и оплатой (Platega), Rai (чат, Code, Слайды, скриншоты) и аккаунты: регистрация, вход, Google, кабинет, чаты в аккаунте | `hosting/rai/` + `chat.html` из `build_standalone.py --cdn` |
| **rteam.info/admin.php** | админ-панель основного сайта; вкладка «Rai: подписки» встроена прямо в неё (один файл) | `make_admin.py` + `hosting/admin/admin_rai.php` |
| **aistudio.rteam.info** | AI Studio: ИИ делает сайты пользователей, API-ключи, хостинг сайтов; вход аккаунтом Rai | `hosting/aistudio/` |

**Быстрее всего:** `python make_hosting.py dist/hosting --zip rai-hosting.zip` соберёт две папки с названиями
доменов (и ZIP). Если перед этим задать переменные `GOOGLE_CLIENT_SECRET` и `SSO_SECRET`, секреты впишутся
в копии `config.php` (в репозиторий они не попадают).

```
            rai.rteam.info                                   aistudio.rteam.info
   чат · Code · Слайды · скриншоты                  сайты пользователей · API-ключи
   регистрация · вход · Google · кабинет  ── sso.php (пропуск) ──►  вход аккаунтом Rai
   чаты хранятся в аккаунте               ── sync.php: имя, почта, удаление ──►
                                             (всё подписано SSO_SECRET)
```

- **Регистрация и вход — на rai.rteam.info**: страница `login.php`, в чате — кнопка «Войти или зарегистрироваться».
- **AI Studio своих паролей не хранит**: «Войти через аккаунт Rai» → rai.rteam.info выдаёт подписанный пропуск
  (действует 2 минуты и один раз) → в студии аккаунт создаётся сам, логин = адрес сайта `sites/<логин>/`.
- **Изменения синхронизируются**: сменили имя, почту или Google в кабинете — это само доходит до AI Studio.
  Удалили аккаунт — удаляются чаты в Rai и сайт с API-ключами в AI Studio.
- Без входа Rai тоже работает — чаты тогда хранятся в браузере.

## 1. Поддомены

Создайте в панели хостинга **rai.rteam.info** и **aistudio.rteam.info** (каждому своя папка), включите HTTPS
(Let's Encrypt) и PHP 7.4 или новее.

## 2. Общий секрет

Придумайте длинную случайную строку (от 32 символов, например 64 символа 0-9a-f) и впишите её **одинаковой**
в `SSO_SECRET` обоих `config.php`. По ней студия проверяет, что пропуск и изменения профиля пришли от Rai.

## 3. rai.rteam.info

Загрузите всю папку `rai.rteam.info/` из сборки — там только `.html` и `.php`:

| Файл | Зачем |
|---|---|
| `index.php` | **главная**: что умеет Rai, тарифы (месяц / год −25%), вопросы. Открывается первой |
| `chat.html` | весь Rai: чат, Code, Слайды, скриншоты и запись экрана; движок и база знаний встроены внутрь |
| `plans.php` | тарифы, подписки, лимиты нейросети, оплата Platega (подключается другими файлами) |
| `limits.php` | для чата: сколько сообщений нейросети осталось сегодня, какие модели доступны |
| `pay.php`, `pay_return.php`, `pay_callback.php` | оплата: заказ → страница Platega → возврат на сайт; уведомление Platega об оплате |
| `admin_api.php` | для вкладки «Rai» в admin.php: статистика, выдача подписок, тарифы. Только подписанные запросы |
| `login.php` | вход и регистрация (логин + пароль или Google) |
| `auth.php` | формы: вход, регистрация, выход, профиль, пароль, удаление аккаунта |
| `account.php` | личный кабинет: профиль, пароль, привязка Google, ссылки на Rai и AI Studio |
| `logout.php` | выход по ссылке (с подтверждением) |
| `google_start.php`, `google_callback.php` | вход через Google |
| `sso.php` | единый вход: выдаёт AI Studio подписанный пропуск |
| `me.php`, `chats.php` | для страницы Rai: кто вошёл, чаты в аккаунте |
| `net.php` | посредник для интернета: погода, курсы, перевод, Википедия, фото и **поиск** идут через ваш сайт. Кэш — в `data/cache/` |
| `social.php` | анализ по ссылке (TikTok, YouTube, Telegram, Instagram, VK, X, сайты) — подключается из `net.php`, сам по себе не открывается |
| `ai.php` | **свой сервер нейросети**: модели Rai Нейро, библиотеки, Python и распознавание текста хранятся на вашем сайте (копии — в `data/ai/`). Первый посетитель сам скачивает их туда, дальше всё грузится с rai.rteam.info. Нужно место: 2–6 ГБ (предел — `AI_MAX_GB` в начале файла) и расширение PHP curl |
| `config.php` | настройки — **впишите секрет Google и SSO_SECRET** |
| `assets/style.php` | стиль страниц входа и кабинета |
| `data/` | аккаунты (пароли — только хеши) и чаты в файлах `*.php` — из браузера не читаются. Нужны права на запись |

Ссылки: `https://rai.rteam.info/` — главная с тарифами, `chat.html` — сам Rai, `chat.html#code` — сразу Code, `chat.html#slides` — Слайды.
**Если на хостинге остался старый `index.html` — удалите его**, иначе вместо главной откроется чат.

### Тарифы и лимиты нейросети

| Тариф | Цена | Нейросеть в день | Модели |
|---|---|---|---|
| без входа | — | 5 | Лайт, Стандарт |
| Старт | 0 ₽ | 15 | Лайт, Стандарт |
| Плюс | 249 ₽/мес | 150 | + Про, «Думать глубже» |
| Премиум | 599 ₽/мес | 600 | все, включая Макс и Код |
| Ультра | 1 290 ₽/мес | без лимита | все |

За год — скидка 25%. Цены, лимиты, названия и описания меняются в админ-панели (вкладка «Rai: подписки» → «Тарифы и лимиты»).
Движок Rai (погода, курсы, перевод, код, презентации) бесплатен всегда: когда сообщения нейросети закончились, отвечает он.
Лимит считает сервер (`limits.php`, файлы `data/usage/`) и обновляется в полночь. Нейросеть работает в браузере посетителя,
поэтому лимит — это ограничение на сайте, а не защита от человека, который сам перепишет страницу.

### Оплата через Platega

1. В кабинете Platega возьмите **Merchant ID** и **секретный ключ** (API).
2. Впишите их в `config.php` на rai.rteam.info: `PLATEGA_MERCHANT_ID` и `PLATEGA_SECRET`.
   `PLATEGA_METHOD`: `0` — покупатель сам выбирает способ на странице Platega, `2` — сразу СБП, `11` — карты.
3. В кабинете Platega укажите адрес уведомлений (callback): `https://rai.rteam.info/pay_callback.php`.

Как идёт оплата: «Подключить» на главной → вход или регистрация → `pay.php` (месяц или год) → страница Platega →
возврат на `pay_return.php`. Подписка включается, когда Platega подтвердит оплату: по уведомлению или при возврате покупателя
(сайт сам спросит статус у Platega). Повторные уведомления подписку не удваивают; поддельные (без вашего ключа) отклоняются,
а статус и сумма всегда перепроверяются у Platega. Подписка не продлевается сама — продление добавляет время к оставшемуся.

### Админ-панель: вкладка «Rai: подписки»

На rteam.info лежит **один файл** `admin.php` — вкладка встроена в него. Всё остальное для Rai — на rai.rteam.info
(`admin_api.php`, `plans.php`, данные в `data/`).

1. Соберите админку: `python make_admin.py старый/admin.php rteam.info/admin.php --key ВАШ_КЛЮЧ`
   (или `make_hosting.py … --admin старый/admin.php` — тогда она попадёт в архив в папку `rteam.info/`).
   Скрипт вставляет код вкладки между метками «RAI: НАЧАЛО / КОНЕЦ» и пять небольших строк (права, меню, вывод,
   плитки на главной, уведомление); ваш код не меняется. Новую версию admin.php можно прогнать ещё раз — вкладка обновится.
2. Тот же ключ (64 случайных символа 0-9a-f) — в `config.php` на rai.rteam.info (`ADMIN_API_KEY`).
   Без `--key` ключ вводится в самой вкладке: «Подключение» → «Сохранить и проверить».

Что есть во вкладке: пользователи, подписчики, доход в месяц, сообщения нейросети за сегодня, графики оплат (30 дней)
и нейросети (7 дней); **выдать подписку по логину** (тариф, срок 7 дней — год или свой, комментарий); поиск, «+30 дн.»,
«Снять»; подсветка подписок, которые кончаются за 3 дня; платежи Platega с кнопкой «Проверить» (если уведомление не дошло);
выгрузка подписчиков и всех пользователей в CSV (Excel); журнал; цены, лимиты и описания тарифов, лимит без входа;
**ключи Platega** (если не вписаны в config.php). На главной админки — плитки «подписчиков Rai» и «оплат Rai за месяц»,
в колокольчике — сколько подписок скоро кончится.
Права: выдавать и снимать — `users.manage`, подключение и тарифы — `settings.manage`. Все действия пишутся в «Логи».

**Своя нейросеть.** Ничего настраивать не нужно: `ai.php` сам скачает модель на сайт при первом запуске.
Адреса вида `ai.php/npm/…` работают на Apache и большинстве хостингов; если на вашем их не пустили (редкие настройки nginx),
модели будут загружаться с Hugging Face, а библиотеки — всё равно с вашего сайта. Проверка: откройте
`https://rai.rteam.info/ai.php/ping` — должно быть `"path_info":true`. Сколько занято: `https://rai.rteam.info/ai.php?status=1`.
В `.htaccess` включены заголовки изоляции страницы — с ними нейросеть на процессоре работает в несколько потоков (быстрее).

**Поиск Google (необязательно).** Без настройки Rai ищет через DuckDuckGo и Википедию. Для Google создайте поисковую
систему на programmablesearchengine.google.com (поиск по всему интернету) и ключ Custom Search API в Google Cloud Console,
затем впишите их в начало `net.php` на хостинге (`GOOGLE_CSE_KEY`, `GOOGLE_CSE_CX`) или задайте переменными окружения.
В GitHub ключи не выкладывайте.

если хостинг их принимает — загрузите (для AI Studio `.htaccess` передаёт заголовок `Authorization` в `api.php`).

## 6. Автовыкладка с GitHub (GitHub → хостинг)

После настройки каждый `git push` сам собирает оба сайта и выкладывает их на хостинг по FTP
(файл `.github/workflows/deploy-hosting.yml`). Выкладываются только изменённые файлы. Папки `data/`
(аккаунты, чаты) и опубликованные сайты `sites/<логин>/` на хостинге **не трогаются**.

Один раз: github.com/rteaminfo1-source/rai → **Settings → Secrets and variables → Actions**.

**Secrets** (вкладка *Secrets*, значения никто не увидит):

| Имя | Что вписать |
|---|---|
| `FTP_SERVER` | адрес FTP из панели хостинга, например `ftp.вашхостинг.ru` |
| `FTP_USERNAME` | логин FTP |
| `FTP_PASSWORD` | пароль FTP |
| `GOOGLE_CLIENT_SECRET` | секрет Google (`GOCSPX-…`) |
| `SSO_SECRET` | длинная случайная строка (64 символа 0-9a-f). Не меняйте её потом — иначе вход в студию перестанет совпадать |

**Variables** (вкладка *Variables*):

| Имя | Что вписать |
|---|---|
| `RAI_DIR` | папка сайта rai.rteam.info на FTP, **со слешем в конце**, например `rai.rteam.info/public_html/` |
| `STUDIO_DIR` | папка сайта aistudio.rteam.info, например `aistudio.rteam.info/public_html/` |
| `FTP_PROTOCOL` | необязательно: `ftps` (по умолчанию, шифрованно) или `ftp`, если хостинг не поддерживает FTPS |
| `FTP_PORT` | необязательно: порт, по умолчанию 21 |

Точные папки видно в файловом менеджере хостинга (часто `домен/public_html/` или `www/домен/`).

Выкладка запускается при push в ветку `main` или `claude/peaceful-allen-c7nn4t`, а также вручную:
**Actions → «Выкладка на хостинг» → Run workflow**. Пока секреты не заданы, выкладка просто пропускается.

## 7. Приложение для компьютера (rai.rteam.info/app/)

На главной есть раздел «Приложение»: сайт сам определяет систему посетителя и показывает нужную кнопку.
Кнопки ведут на `download.php?os=win|mac|mac-x64|linux|deb`: он считает скачивания (видно в админке, вкладка «Rai»)
и отдаёт файл из папки `app/` на хостинге, а если его там нет — из последнего релиза на GitHub.

Файлы приложения собирает GitHub (**Actions → «Приложение Rai»**, файл `.github/workflows/desktop.yml`) после каждого
push, который меняет Rai, и выпускает релиз в **Releases**. Если заданы те же FTP-секреты и `RAI_DIR`, что и для
выкладки сайта, файлы кладутся ещё и в `rai.rteam.info/app/` — оттуда приложения обновляются, если GitHub недоступен.
Не хотите хранить ~700 МБ на хостинге — создайте переменную `APP_TO_HOSTING` со значением `false`.

Положить файлы вручную: загрузите в `app/` на хостинге `Rai-Setup.exe`, `Rai-mac-arm64.dmg` (или `.zip`),
`Rai-mac-x64.dmg` (или `.zip`), `Rai-linux.AppImage`, `Rai-linux.deb` и рядом `latest.yml`, `latest-mac.yml`,
`latest-linux.yml` (по ним приложения узнают версию). Файлы `.htaccess` и `web.config` в `app/` уже есть в архиве.

## Если погода, поиск или анализ ссылок не работают

1. Откройте `https://rai.rteam.info/net.php?ping=1` — должно быть `{"ok":true,"service":"rai-net"}`. Нет такого ответа —
   загрузите `net.php` и `social.php` из архива в корень сайта.
2. Нужно расширение PHP **curl** (в панели хостинга: «Версия PHP» → «Расширения»).
3. Папка `data/` должна быть доступна PHP на запись (права 755 или 775) — там кэш ответов.
4. В окне просмотра Claude интернет закрыт самой площадкой: там Rai честно об этом пишет и отправляет на rai.rteam.info.

Страница сама находит `net.php` (ждёт ответа до 7 секунд, если хостинг «просыпается», и проверяет ещё раз через 15 и 60 секунд),
а если прямой запрос к сервису погоды не прошёл — повторяет его через ваш сайт. Крупные города (≈200) Rai знает сам,
поэтому «погода в Минске» не требует поиска города в интернете.

## Что не выкладывать в GitHub

`config.php` с секретами, папки `data/` и `sites/` с хостинга. В репозитории оба `config.php` лежат без секретов.
